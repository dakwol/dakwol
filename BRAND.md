## Принципы

1. Основной акцент принадлежит бренду команды СБОРКА.
2. Визуальный язык сочетает инженерный интерфейс, GIS-сетки и 3D wireframe.
3. Анимации реализованы внутри SVG без JavaScript.
4. Текстовая версия содержимого остаётся в README для доступности и индексации.
5. Профиль избегает стены бейджей и стандартных GitHub-карточек.
